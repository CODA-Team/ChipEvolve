# Historical records and experiments

These 377 files preserve the original bytes and attribution. They are evidence
of earlier work, not current installation, runtime or test entry points.

- `records/`: 256 reports, plans and frozen evidence files.
- `experiments/`: 121 earlier experiment, ablation and delivery files.
- [INDEX.csv](INDEX.csv): original path, current path, SHA256, category and source state.

References inside frozen files describe their original workspace. Moving a
historical script does not qualify it to run in the current environment. Use
[the quickstart](../README.md), [runtime tools](../admin/README.md) and
`tests/support/` for maintained consumers. `discarded/` separately preserves
the previous implementation and supplies no current business interfaces.

Seventeen unaccepted local files remain protected at their original `admin/`
paths in the owner's original workspace. They are excluded from this delivery;
see the catalog's explicit local-only rows. No user experiment data was moved.

For a protected path already tracked in the public baseline, its earlier committed
version may remain in this clean checkout; the owner's unaccepted bytes or
modifications are excluded and stay untouched in the original workspace.
