# Generated Student Command Scripts

These scripts are generated by the Teacher/Student orchestrator. Use them
instead of reconstructing build, evaluator, git, or diff commands.

Minimal flow:

1. If Teacher assigns a prepared start point, run
   `01_prepare_start_source.sh --kind <framework|diamond|evolved_diamond|evolved_legalm|evolved_negotiation>`
   before edits. Otherwise run `00_prepare_source.sh` once.
2. For each mechanism trial:
   - `25_trial_source.sh begin --label <short-mechanism>`
   - or, when Teacher asks to repair a prior rejected/kept mechanism:
     `25_trial_source.sh begin --label <repair-name> --from-ref <ref>`
   - edit source, then run `10_build_variant.sh` and `20_evaluate_candidate.sh`
   - `20_evaluate_candidate.sh` auto-generates `candidate_metrics_summary.json/md`; use that summary before keep/reject
   - if rejected: `25_trial_source.sh reject --reason "<why>"`
   - if retained: `25_trial_source.sh keep --reason "<why>"`
3. Final retained source:
   - `30_finalize_source.sh`

The trial helper is a safety state machine. `reject` commits and pins a
`rejected/<run_tag>/...` branch, writes diff/metrics evidence into
`source_trials.jsonl`, restores the iteration branch to the begin checkpoint,
and removes stale canonical metrics so the retained source must be evaluated
again before finalization. `keep` pins a `kept/<run_tag>/...` ref and leaves the
iteration branch at the kept source. `begin --from-ref` lets a later repair
trial continue from a rejected/kept branch while still restoring to the current
base if the repair is rejected.

Optional helpers:

- `02_source_status.sh`: verify branch, base commit, candidate refs, and start
  branches.
- `03_fetch_peer_source.sh --peer-repo <repo> --peer-ref <ref> --label <name>`:
  fetch another Student's mechanism as `peer/<label>` and write a diff under
  artifacts without changing your working tree.
- `04_switch_start_branch.sh --kind <kind>`: switch start branch after
  `00_prepare_source.sh` when Teacher explicitly assigns a start.
- `05_source_context.sh <src/...> [symbol]`: print current local source context
  for an edit anchor.
- `08_query_knowledge.sh --stage <stage> --q <text>`: query one concise
  mechanism card or skill id.
- `11_build_variant_fresh.sh`: use only when the normal build script fails or
  leaves the private binary missing.
- `21_report_candidate_metrics.sh`: regenerate the canonical candidate metrics
  summary from `metrics.json` and the referenced DPL log.
- `25_trial_source.sh status`: inspect active trial state and recent trial log.
- `run_after_edit.sh`: build, evaluate, and finalize after source edits are
  already complete and no active trial remains.

Student start-point switches are branch-only. Use the prepared git start
branches and then commit local source edits.

Run helpers that mutate the private source repo serially. Do not launch
prepare, switch, build, evaluate, trial, or finalize helpers in parallel. They
share one private git repo and are protected by a file lock.
