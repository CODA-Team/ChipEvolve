# Packets

This directory mixes two kinds of files:

## Generated current packet

- `current_run_packet.md`
- `current_run_packet.json`

These are **derived artifacts** generated by `kb_query.py`.

They are useful as the most recent compact context snapshot, but they should
not be treated as hand-maintained source documents. They are intentionally
ignored by git so refreshes do not dirty the repo for loop-driven runs.

## Templates / schema

- `bootstrap_packet.template.md`
- `patch_packet.template.md`
- `current_run_packet_template.md`
- `kb_packet_schema.yaml`
- `project_context_current.md`

These files explain or template packet structure.

## Rule

When in doubt:

- read `current_run_packet.md` for the latest compact context
- edit templates or source knowledge, not the generated packet, when you want
  a persistent change
