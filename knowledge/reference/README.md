# Reference Materials

This directory keeps algorithm references for `dpl_evolve_agent`.

- The OpenDP-named committed reference is a fence-region-aware mixed-height
  legalization paper, not OpenROAD DPL engine documentation.
- `papers/` stores the curated paper index and optional source-verification
  instructions.
- `commands.txt` stores OpenROAD command-reference snippets.

Do not commit papers whose redistribution status is unclear.  Use
`papers/paper_sources.yaml` and `scripts/fetch_reference_papers.sh` only when a
task explicitly needs source-text verification.
