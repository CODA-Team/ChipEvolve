# Reference Materials

This directory keeps algorithm references for `dpl_evolve_agent`.

- `OpenDP.pdf` is already committed and can be used directly by research
  agents.
- `papers/` stores the curated paper index and local PDF cache instructions.
- `commands.txt` stores OpenROAD command-reference snippets.

Do not commit papers whose redistribution status is unclear.  Use
`papers/paper_sources.yaml` and `scripts/fetch_reference_papers.sh` to build a
local cache instead.
