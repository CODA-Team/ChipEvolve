# Knowledge Archive

Archive files are preserved for forensic review and migration history. They are
not active route knowledge, should not appear in default Teacher or Student
context, and should not be queried by `scripts/repo/query_knowledge.py`.

- `context_audit_legacy.md`: historical context audit.
- `commands_legacy.txt`: old command-reference snippets.
- `insights_readme_legacy.md`: pre-taxonomy insights directory note.

If an archived lesson becomes useful again, migrate the reusable mechanism into
the active taxonomy under `knowledge/routing/`, `knowledge/skills/`, or
`knowledge/support/`; do not point new prompts at archive files directly.
